## Topics

IPOS, hardware and software, command-line file operations, operating-system responsibilities, processes and permissions, Python execution, compiler/interpreter differences, decimal/binary/hexadecimal conversion, text encoding, version control and basic networking.

## Run the converter

From this repository, run `python3 mission-05-numbers-data/number_converter.py`, enter a positive whole number, and read the binary and hexadecimal outputs.

## Learning summary

The project connects basic ideas: input data is processed and stored; the operating system manages shared hardware; programs represent and transform data; and networks let clients request services from servers. Git records the project’s changes so they can be reviewed.
