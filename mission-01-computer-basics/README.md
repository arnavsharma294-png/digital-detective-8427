# Mission 1 — Know your computer

## 1. Task / objective
Explain IPOS, classify hardware and software, and identify everyday computer systems.

## 2. Work completed
### IPOS example: saving a document
| Stage | What happens | Component |
|---|---|---|
| Input | I type words and choose Save. | Keyboard, trackpad |
| Processing | The application handles the text and save request. | CPU and memory |
| Output | The document and save status appear. | Display |
| Storage | The file is written for later use. | SSD or cloud storage, if selected |

### Hardware and software examples
| Item | Classification | Type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | — | Enters text |
| Trackpad | Hardware | — | Moves pointer and selects items |
| Display | Hardware | — | Shows information |
| SSD | Hardware | — | Stores files persistently |
| macOS | Software | Operating system | Manages hardware and runs applications |
| Web browser | Software | Application | Opens websites |
| Text editor | Software | Application | Creates and edits text |
| Backup utility | Software | Utility | Helps preserve copies of data |

### Computer systems around me
| System | Main purpose | Input | Output |
|---|---|---|---|
| ATM | Banking transactions | Card and PIN entry | Cash or receipt |
| Traffic signal controller | Controls road traffic | Sensors or timed schedule | Signal lights |
| Smart TV | Plays media | Remote control | Picture and sound |

## 3. Commands / tools used
Markdown tables were used to organize examples; no Terminal commands were needed for the concepts.

## 4. My understanding
A computer takes input, processes it using instructions, produces output, and often stores the result. Hardware is the physical equipment; software gives the equipment instructions. Many everyday devices are specialized computer systems.
